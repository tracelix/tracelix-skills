# Tracelix Skills

Скиллы для агентов разработки, позволяющие создавать и использовать контекстный граф в [Tracelix](https://tracelix.ru). Каждый скилл можно использовать
отдельно или вместе с другим.

| Скилл | Назначение |
| --- | --- |
| [Tracelix Context Bootstrap](skills/tracelix-context-bootstrap/SKILL.md) | Изучить возможности, правила и зависимости репозитория; сформировать и отправить первоначальные знания |
| [Tracelix Context Awareness](skills/tracelix-context-aware/SKILL.md) | Оценить влияние изменений перед разработкой, а после неё опубликовать вновь полученные знания об изменении |

## Требования

- Агент разработки с поддержкой скиллов, доступом к локальным файлам, возможностью
  выполнения команд и встроенным MCP-клиентом с поддержкой Streamable HTTP и
  аутентификации по Bearer-токену.
- Node.js 22.20+ и npm для установки через `npx skills` или Git для установки
  напрямую из GitHub, описанной ниже.
- Python 3.9+ для входящего в комплект инструмента рендеринга, который использует
  только стандартную библиотеку.
- Контекст Tracelix с настроенными моделями эмбеддингов и генерации.

## Установка

Запустите команду из целевого проекта и выберите своего агента разработки, когда
появится соответствующий запрос. Чтобы установить оба скилла:

```bash
npx skills add tracelix/tracelix-skills --skill '*'
```

Или установите нужный скилл отдельно:

```bash
npx skills add tracelix/tracelix-skills --skill tracelix-context-bootstrap
npx skills add tracelix/tracelix-skills --skill tracelix-context-aware
```

Добавьте `-g` для установки на уровне пользователя или `--copy`, чтобы скопировать
файлы вместо создания символических ссылок. Выбор агента и другие параметры описаны
в [справочнике установщика](https://github.com/vercel-labs/skills/blob/main/docs/commands.md).

### Установка напрямую из GitHub

Если `npx` недоступен или завершается с ошибкой из-за требований вашего проекта к
Node.js, клонируйте репозиторий и скопируйте папки скиллов целиком. Выполните команды
из корня целевого проекта в Linux, macOS или WSL:

```bash
skills_source=$(mktemp -d)
git clone --depth 1 https://github.com/tracelix/tracelix-skills.git "$skills_source"
mkdir -p .agents/skills
cp -R "$skills_source/skills/tracelix-context-aware" \
      "$skills_source/skills/tracelix-context-bootstrap" \
      .agents/skills/
```

Замените `.agents/skills/` на каталог скиллов вашего агента в проекте, если он
отличается. Чтобы установить только один скилл, оставьте в команде копирования
только исходную папку этого скилла. Сохраните все входящие в комплект файлы, а после
установки перезагрузите скилли агента.

Этот способ установки использует Git и стандартные инструменты командной оболочки,
не вызывая npm и не меняя версию Node.js в проекте. Для обновления потребуется
повторно скопировать папки с новыми версиями скиллов.

## Подключение Tracelix

1. Создайте сервисного пользователя в настройках **Service users** нужного контекста
   и сохраните показанный при создании токен в безопасном месте.
2. Получите у администратора Tracelix адрес конечной точки Streamable HTTP `/mcp`.
3. Зарегистрируйте сервер в настройках MCP вашего агента, используя параметры
   подключения из таблицы ниже. Синтаксис конфигурации и способ хранения секретов
   зависят от агента; для токена используйте поддерживаемый им механизм секретов
   или переменных окружения.
4. Подключите или перезагрузите сервер, затем попросите агента вызвать
   `get_context_readiness({})`. Успешный ответ подтверждает подключение. Если
   `ready` имеет значение `false`, выполните указания из полученного сообщения,
   чтобы завершить настройку в Tracelix, и повторите проверку. Эта проверка не
   обращается к провайдерам моделей, поэтому их доступность проверяется при
   использовании скиллов.

| Параметр | Значение |
| --- | --- |
| Транспорт | Streamable HTTP |
| URL сервера | Адрес, предоставленный администратором, например `https://api.tracelix.ru/mcp` |
| Аутентификация | Токен сервисного пользователя, передаваемый в заголовке `Authorization: Bearer <SERVICE_USER_TOKEN>` |

Убедитесь, что через это подключение агенту доступны следующие инструменты:

| Инструмент | Использование |
| --- | --- |
| `get_context_readiness` | Оба скилла: проверка подключения и готовности конфигурации |
| `get_context_ontology` | Оба скилла: чтение активной онтологии |
| `submit_context_knowledge` | Оба скилла: отправка структурированных знаний |
| `get_context_ingestion_run` | Оба скилла: отслеживание запущенной обработки отправленных знаний |
| `list_context_ingestion_runs` | Оба скилла: просмотр истории обработки знаний |
| `ask_context_graph` | Context Awareness: получение контекста перед разработкой и поиск опубликованных знаний после неё |

скилли отправляют в этот контекст Tracelix описания, связи, пути к исходным файлам,
хеши и привязки к подтверждающим фрагментам, полученные из репозитория. Настройка
MCP-подключения и аутентификации выполняется отдельно от установки скиллов.

## Использование

Откройте целевой репозиторий в агенте. Выберите скилл через меню скиллов агента или
с помощью его синтаксиса вызова либо запросите скилл по имени. При необходимости
укажите агенту путь к файлу `SKILL.md` установленного скилла.

Для формирования первоначальных знаний о репозитории:

```text
Используй скилл tracelix-context-bootstrap, чтобы сформировать первоначальные знания об этом репозитории.
```

Для дальнейшей разработки:

```text
Используй скилл tracelix-context-aware, чтобы реализовать это изменение с учётом подключённого графа контекста.
```

Артефакты знаний и журналы отправок сохраняются в каталоге `.tracelix/` целевого
проекта. Требования к инструментам и порядок обработки знаний описаны в
[справочнике по загрузке первоначальных знаний](skills/tracelix-context-bootstrap/references/ingestion.md)
и [контракте MCP для разработки](skills/tracelix-context-aware/references/mcp-contract.md).
